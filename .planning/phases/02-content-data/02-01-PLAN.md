# Plan 02-01: Content Data Files

**Phase:** 2 — Content Data Files
**Plan:** 02-01
**Goal:** Typed TypeScript content for all portfolio sections (hero, projects, skills, experience, education, contact)
**Requirements**: HERO-01, HERO-02, PROJ-01, PROJ-02, PROJ-03, PROJ-04, PROJ-05, SKILLS-01, EXP-01, EDU-01, CONTACT-01
**Depends on:** Phase 1 (Foundation)

---

## Task 1: Create Content Interfaces

**Goal:** Define TypeScript interfaces for all content types

**Do:**
- Create `Website/src/types/content.ts` with interfaces:
  - `HeroData` — name, title, intro, ctaLabel, ctaHref
  - `Project` — id, title, problem, data, method, findings, impact, github, visualization?
  - `Skills` — languages, frameworks, tools, domains (all string arrays)
  - `Experience` — timeline with role, company, period, achievements
  - `Education` — degree, institution, year, details
  - `Contact` — email, linkedin, github, resume?
  - `PortfolioContent` — aggregated type exporting all sections

**Verify:**
- [ ] All interfaces exported
- [ ] Types align with DESIGN.md patterns (no shadows, terminal-native)

## Task 2: Create Hero Content

**Goal:** Hero section data with real name, title, and intro

**Do:**
- Create `Website/src/content/hero.ts`

- Export typed `HeroData` object

**Verify:**
- [ ] TypeScript compiles (`npx tsc --noEmit`)
- [ ] CTA href is a valid URL

## Task 3: Create Projects Content

**Goal:** 3-5 project case studies following Problem → Data → Method → Findings → Impact

**Do:**
- Create `Website/src/content/projects.ts`
- Include 3-5 projects with:
  - Problem statement (business context, not technical)
  - Data description (sources, size, type)
  - Method (approach, not just algorithm names)
  - Findings (key discoveries)
  - Impact (business outcomes, quantified where possible)
  - GitHub repository link
  - Optional visualization description
- Export typed `Project[]` array

**Verify:**
- [ ] At least 3 projects included
- [ ] No tutorial datasets (Titanic/Iris/MNIST)
- [ ] Impact section quantifies outcomes (%, $, time saved)
- [ ] Each project has GitHub link
